# Spanish (es-US) — Review Doc

One review pass sets the register for everything. Format: English source |
Spanish draft | term notes. Register: **cálido y elegante** — warmer than the
English copy on purpose; restraint stays in the visuals, warmth goes in the
words. French product names stay French. Drafts use **tú** (Miami-normal for
this category) — reviewer to confirm. All Spanish ships behind `SPANISH_ACTIVE`,
off until this doc is approved.

**Register rules CONFIRMED by the reviewer (2026-07-26) — apply to all future Spanish:**
- No gendered greetings: "Te damos la bienvenida", never "Bienvenida/Bienvenido"
- No English serial commas: never a comma before *o*/*y* closing a list
- Idiomatic thresholds: "a partir de $100", not "en pedidos desde"
- Every link sent to Spanish speakers uses the /es path
- Warmth via direct address of the item (lávala / sécala) beats label-speak
- Never "gentil" for products — suave / delicado (gentil = courteous person)
- Never gender the baby: "con tu bebé", not con él/ella
- Craft verbs must be factual: tejida solo si es tejido, trenzado se trenza, "ilustrada a mano" solo si es ilustración real
- Vary sentence openers — no "Como…" formula repeated across descriptions that sit side by side
- UI labels in sentence case ("Envío gratis"), not Title Case
- Policy text in present tense ("Si algo no llega bien")

**Standing term choices for the reviewer to confirm once:**
- *canastilla* (drafted) vs *cesta* vs *caja* — for the gift box itself
- *posparto* (drafted) vs *cuarentena* — for the postpartum period
- *muselina* — for muslin; *manta tejida* — for the knit blanket
- Emoji frequency — drafts lean warm; dial to taste
